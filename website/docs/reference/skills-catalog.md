# Bundled Skills Catalog

Cryozen ships with a large built-in skill library copied into `~/.cryozen-agent/skills/` on install. Each skill below links to a dedicated page with its full definition, setup, and usage.

Cryozen also syncs bundled skills on `cryozen update`, but the sync manifest respects local deletions and user edits. If a skill listed here is missing from your profile's `~/.cryozen-agent/skills/` tree, it is still shipped with Cryozen; restore it with `cryozen skills reset <name> --restore`.

If a skill is missing from this list but present in the repo, the catalog is regenerated by `website/scripts/generate-skill-docs.py`.
